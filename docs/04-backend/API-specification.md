## 1. Global API Standards & Conventions

### 1.1 Headers
| Header | Type | Description |
| :--- | :--- | :--- |
| `Authorization` | String | Standard bearer token: `Bearer <jwt_token>` |
| `Content-Type` | String | `application/json; charset=utf-8` |
| `X-Correlation-Id` | UUID | Distributed tracing identifier generated by client or gateway |
| `Idempotency-Key` | UUID | **Mandatory on all financial payment & offline sync mutations** |

### 1.2 Response Envelope Format

#### Success Envelope (`ApiResponse<T>`):
```json
{
  "success": true,
  "data": { ... },
  "message": "Operation completed successfully.",
  "timestamp": "2026-11-01T14:00:00Z"
}
```

#### Paginated Envelope (`PagedResponse<T>`):
```json
{
  "success": true,
  "data": [ ... ],
  "pagination": {
    "pageNumber": 1,
    "pageSize": 25,
    "totalCount": 240,
    "totalPages": 10,
    "hasNextPage": true,
    "hasPreviousPage": false
  },
  "timestamp": "2026-11-01T14:00:00Z"
}
```

#### Error Envelope (RFC 7807 Problem Details):
```json
{
  "type": "https://api.fidelhub.com/errors/validation-error",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "detail": "Please refer to the errors property for additional details.",
  "instance": "/api/v1/finance/payments",
  "traceId": "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01",
  "errors": {
    "Amount": ["Payment amount must be greater than zero."],
    "IdempotencyKey": ["Idempotency-Key header is required for payment operations."]
  }
}
```

## 2. Comprehensive Endpoint Catalog

### Module 01: Organization, Branches & Calendar
* `GET /api/v1/organizations/profile` — Retrieve tenant organization metadata.
* `PUT /api/v1/organizations/profile` — Update organization branding and contact details.
* `GET /api/v1/branches` — List campus branches for current tenant.
* `POST /api/v1/branches` — Provision a new branch campus.
* `GET /api/v1/calendar/academic-years` — Retrieve academic calendar years (EC and GC mappings).
* `POST /api/v1/calendar/academic-years` — Configure a new academic year and terms.

### Module 02: Identity & Session
* `GET /api/v1/auth/me` — Retrieve current authenticated user profile, active branch, and permissions.
* `POST /api/v1/auth/switch-branch` — Request a scoped JWT token for another authorized branch.
  - Body: `{ "targetBranchId": "uuid" }`

### Module 03: Student Information System & Admissions
* `POST /api/v1/admissions/applications` — Submit online admission intake application.
* `GET /api/v1/admissions/applications` — List applications filterable by status (`SUBMITTED`, `REVIEW`).
* `POST /api/v1/admissions/applications/{id}/approve` — Approve application & generate student profile.
* `GET /api/v1/students` — Search student directory (Pagination, query by name, grade, admission #).
* `GET /api/v1/students/{id}` — Retrieve full student profile, guardians, and academic enrollments.
* `PUT /api/v1/students/{id}` — Update student biodata and address.
* `POST /api/v1/students/{id}/transfer` — Initiate branch-to-branch student transfer.

### Module 04: Academics, Timetable & Behavioral Traits
* `GET /api/v1/academics/classes` — List class grade levels and active sections.
* `POST /api/v1/academics/classes` — Create grade level and assign streams.
* `GET /api/v1/academics/timetables/sections/{sectionId}` — Retrieve weekly section schedule grid.
* `PUT /api/v1/academics/timetables/sections/{sectionId}` — Update timetable slots with collision validation.
* `POST /api/v1/academics/lessons` — Submit weekly lesson plan for HOD review.
* `PUT /api/v1/academics/lessons/{id}/review` — Approve or reject lesson plan with comments.
* `POST /api/v1/academics/traits/evaluate` — Submit affective and psychomotor ratings (1–5 scale).
* `POST /api/v1/academics/nursery/activities` — Submit daily feeding, nap, and milestone log for KG.

### Module 05: Attendance Tracking
* `GET /api/v1/attendance/roster?sectionId={id}&date={date}` — Get pre-populated daily attendance roster.
* `POST /api/v1/attendance/sessions` — Submit morning or period attendance session.
* `PUT /api/v1/attendance/records/{id}/correct` — Edit historical attendance record with reason code.
* `GET /api/v1/attendance/reports/truancy` — Retrieve unexcused absence escalation report.

### Module 06: Question Bank & Offline CBT Engine
* `GET /api/v1/question-banks` — List question banks tagged by subject and grade level.
* `POST /api/v1/questions` — Author rich question with KaTeX math and media attachments.
* `POST /api/v1/questions/bulk-import` — Upload ZIP/CSV question bank bundle.
* `POST /api/v1/examinations/papers` — Assemble exam paper (manual or blueprint randomization).
* `GET /api/v1/examinations/papers/{id}/package` — Download AES-256 encrypted exam package for local venue server.
* `POST /api/v1/cbt/sessions/sync` — **Idempotent batch upload of completed student exam sessions from Local Venue Server**.
  - Body: `{ "batchToken": "uuid", "venueServerId": "string", "sessions": [ ... ] }`
* `POST /api/v1/examinations/theory/grade` — Teacher portal to grade subjective essay questions using rubrics.

### Module 07: Continuous Assessment, Gradebooks & Report Cards
* `GET /api/v1/grades/marksheet?sectionId={id}&subjectId={id}` — Retrieve spreadsheet marksheet grid.
* `PUT /api/v1/grades/marksheet/entry` — Update continuous assessment or final exam marks.
* `POST /api/v1/grades/marksheet/lock` — Formally lock term marksheet from further teacher modifications.
* `POST /api/v1/grades/report-cards/generate-batch` — Trigger background generation of dual-script PDF report cards.
* `GET /api/v1/grades/verify/{hash}` — Public verification endpoint for QR codes on printed report cards.

### Module 08: Student Fee Management & Invoicing (No General Ledger)
* `GET /api/v1/finance/structures` — List fee structures for active academic year.
* `POST /api/v1/finance/invoices/generate-batch` — Batch generate term fee invoices for enrolled students.
* `POST /api/v1/finance/invoices/{id}/post` — Finalize and lock invoice (`DRAFT` → `POSTED`).
* `POST /api/v1/finance/payments` — **Collect fee payment with mandatory `Idempotency-Key` header**.
  - Body: `{ "invoiceId": "uuid", "amount": 4500.00, "channel": "TELEBIRR", "referenceNumber": "TLB-94821" }`
* `GET /api/v1/finance/receipts/{id}` — Download printable PDF official payment receipt.
* `GET /api/v1/finance/statements/{studentId}` — Retrieve complete student fee ledger and balance due.

### Module 09: Communications & Notifications
* `POST /api/v1/communications/broadcast` — Send SMS broadcast announcement (filter by grade/branch).
* `GET /api/v1/communications/delivery-logs` — Review SMS dispatch and delivery status.

### Module 10: Reporting & Transcripts
* `GET /api/v1/reports/executive-dashboard` — High-level KPI summary (enrollment, attendance, fee collection).
* `GET /api/v1/reports/transcripts/{studentId}` — Generate multi-year official transcript PDF.

### Module 11: Library & Digital Media Management
* `GET /api/v1/library/books` — Search physical and digital book catalog (ISBN, title, author, category).
* `POST /api/v1/library/books` — Register new book title with total copies and shelf location.
* `POST /api/v1/library/loans/checkout` — Issue book loan to student or staff member.
  - Body: `{ "bookId": "uuid", "borrowerType": "STUDENT", "borrowerId": "uuid", "dueDays": 14 }`
* `POST /api/v1/library/loans/{id}/return` — Process book return, evaluate condition (`GOOD`, `DAMAGED`, `LOST`).
* `GET /api/v1/library/digital-resources` — Access downloadable curriculum PDFs and syllabus media.

### Module 12: Facilities & Laboratory Management
* `GET /api/v1/facilities/equipment` — List science apparatus and ICT lab equipment by branch and room.
* `POST /api/v1/facilities/lab-bookings` — Reserve laboratory room for scheduled class experiment.
  - Body: `{ "facilityName": "Chemistry Lab", "sectionId": "uuid", "subjectId": "uuid", "bookingDate": "2026-11-10", "periodNumber": 3, "purpose": "Acid-Base Titration" }`
* `POST /api/v1/facilities/incidents` — Log equipment breakage or safety infraction.

### Module 13: Student Health & Clinic Dispensary
* `GET /api/v1/health/profiles/{studentId}` — Retrieve student blood group, allergies, and chronic conditions.
* `PUT /api/v1/health/profiles/{studentId}` — Update student emergency medical record.
* `POST /api/v1/health/clinic-visits` — Record student clinic visit, vitals, triage level, and medications.
  - Body: `{ "studentId": "uuid", "temperatureCelsius": 39.1, "symptoms": "High fever", "triageLevel": "SEVERE", "treatmentAdministered": "Paracetamol + Rest", "restBedAssigned": true, "escalateUrgent": true }`

### Module 14: Teacher Grade Modification Audit Trail
* `GET /api/v1/audit/grades` — Query marksheet modification audit logs (filter by teacher, student, date range).
* `GET /api/v1/audit/grades/out-of-window` — Review flagged grade changes executed after lock deadline.

### Module 15: Platform SuperAdmin & Quota Management
* `GET /api/v1/platform/tenants` — List all registered school organizations on SaaS platform.
* `POST /api/v1/platform/tenants` — Provision new school tenant with subscription plan tier.
* `PUT /api/v1/platform/tenants/{id}/quota` — Adjust maximum enrolled student limit and branch allowance.
* `POST /api/v1/platform/tenants/{id}/backup-export` — Trigger encrypted tenant database export.
