All assets are editable SVG files. Open in Figma, Illustrator, Inkscape, or a code editor.

Included:
- Primary horizontal logo

- Green symbol variation
- White wordmark for dark backgrounds
- Four feature icons
- Brand color palette
- Green and off-white presentation backgrounds

Brand colors:
Deep green  #1B5E3F
Warm gold   #E0A526
Dark ink    #1F2933
Off-white  #FAF7F0

Note: The Ge'ez letter is live text in the logo SVG. For identical rendering across systems,
use a font that supports Ethiopic characters (for example Noto Sans Ethiopic or Abyssinica SIL),
or convert the text to outlines in your vector editor before production.
